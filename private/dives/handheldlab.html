HANDHELDLAB

A desktop tool that tells you how your PC game build will actually behave on a Steam Deck, ROG Ally, or Legion Go — with numbers it can defend, and honest labels on the ones it can't.

STACK: Tauri (Rust) + TypeScript + Vite TIMELINE: Jul 2026 → present ROLE: measurement, model, UI — all of it

PLANNING

/ the brainstorm & the research
THE PREMISE

"You cannot accurately predict handheld framerates from a desktop PC. Anything that claims to is inventing a number. So don't predict — measure where you can, model where you can't, and always label which one you're looking at."

RESEARCH TRAIL
  • → Hardware deep-dives: Steam Deck (LCD/OLED), ROG Ally / Ally X, Legion Go
  • → Why desktop→handheld scaling lies: power limits, memory bandwidth, thermals
  • → Measurement-transfer methodology — benchmarking without a benchmark rig
  • → Argon2 — doing password hashing properly on day one

BRAIN DUMP #1

It's a measurement-transfer tool, NOT a predictor. The difference is the whole product.

BRAIN DUMP #2

Every performance figure carries a confidence tier. T0 makes no framerate claims at all — and says so proudly.

CONSTRAINTS

  • Never invent a framerate. Ever.
  • Desktop app — it inspects real builds, not web demos.
  • Model output must be visually distinct from measured output.

DECISION! Tauri over Electron

The measurement engine wants to be native anyway — Rust does the math, the webview only draws. The app stays small, and a benchmarking tool that hogs resources would be a joke that writes itself.

DECISION! Confidence tiers over point estimates

"38–45fps, GPU-bound, T1 modelled" is honest. "42fps" is marketing. Every figure in the app wears its tier like a badge, and T0 results refuse to show a framerate at all.

LESSONS LEARNED

/ scars, itemized
#1
Honesty is a feature you have to build.

Labelling every number as measured-vs-modelled isn't a disclaimer buried in settings — it's the core UI. The tier badge took real design work, and it's the thing that makes the tool trustworthy.

#2
Draw the Rust/TypeScript border early.

Math, models, and file inspection live in Rust; TypeScript only presents. Every time logic leaked into the webview it eventually had to be dragged back across the Tauri command boundary.

#3
The tool grew a website before it grew a second tier.

Landing page, account registration, Argon2 auth — all shipped while T2 (measured-on-device) was still a README bullet. Infrastructure is comfort food; the hard measurement work is the actual meal.
